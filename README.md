# Dua Finder
Production-ready Islamic dua finder website built with Next.js App Router, TypeScript, Tailwind CSS, SEO metadata, schema helpers, live search, categories, blog, bookmarks, recently viewed, and responsive Islamic UI.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm run start
```

## Deploy
Upload to GitHub and deploy on Vercel. Add `NEXT_PUBLIC_SITE_URL` in environment variables.
